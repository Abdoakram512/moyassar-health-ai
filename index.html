Three Specialized Medical AI Engines

Production-engineered pipelines addressing mission-critical clinical triage across hematology, dentistry, and neuro-oncology.

Moyassar Hema

Automated Blood & CBC Diagnostics

Comprehensive web platform for blood test automation and Complete Blood Count (CBC) analysis. Features automated anemia subtype classification (Microcytic, Macrocytic, Normocytic) with OpenCV cell segmentation.

  • ✓ Automated CBC biomarker parsing (RBC, HGB, MCV, MCH)
  • ✓ Instant differential anemia diagnosis
  • ✓ Patient, doctor, and laboratory multi-tenant workflow
  • ✓ Full REST API + automated deployment pipeline
Flask OpenCV Python SQLite
Moyassar Dental

Deep-Learning Dental Pathology Suite

Clinical-grade dental disease detection utilizing deep learning. Combines ResNet-50 multi-label classification (91.06% accuracy) with YOLOv8 object detection for bounding-box pathology localization.

  • ✓ Simultaneous detection of 6+ concurrent dental pathologies
  • ✓ Precise bounding box lesion localization (0.78 mAP@0.5)
  • ✓ High-throughput bitewing & panoramic image screening
  • ✓ Node/Express microservice with MongoDB storage
YOLOv8 ResNet-50 Node.js MongoDB
